# ROALDIX Technologies — Landing Page

Landing page corporativa de **ROALDIX Technologies**, una marca tecnológica con sede en México enfocada en el desarrollo de software a medida, soluciones web e informatización de procesos para empresas.

## 🎯 Propósito

Esta página sirve como punto de entrada principal para clientes potenciales que buscan servicios de desarrollo tecnológico. Presenta la identidad de la empresa, su oferta de servicios, metodología de trabajo, y canales de contacto para solicitar cotizaciones.

## 📋 Secciones

| Sección | Descripción |
|---|---|
| **Hero** | Presentación principal con el eslogan *"Tecnología que transforma ideas en soluciones digitales"* y llamadas a la acción hacia servicios y cotización por WhatsApp. |
| **¿Quiénes somos?** | Descripción de la empresa, su misión (desarrollar soluciones confiables que optimicen procesos) y visión (consolidarse como marca reconocida por innovación digital). |
| **Nuestros Valores** | Seis pilares: Innovación, Calidad, Compromiso, Adaptabilidad, Transparencia y Confidencialidad. |
| **Servicios** | Catálogo de seis servicios: Desarrollo a medida, Diseño Web, Informatización, Inteligencia Artificial, Bases de datos y Soporte tecnológico. |
| **Metodología** | Proceso de trabajo en 6 etapas: Análisis → Planificación → Diseño → Desarrollo → Pruebas → Entrega. |
| **¿Por qué elegirnos?** | Diferenciadores clave: soluciones adaptadas, resultados prácticos, visión de crecimiento, comunicación clara y tecnología con propósito. |
| **Sectores** | Industrias atendidas: Comercio y distribución, Servicios profesionales, PyMEs, Agroindustria, y Emprendimientos digitales. |

| **Contacto** | Email (`info@codecoresystems.com`), WhatsApp (`+52 971 564 4650`) y ubicación (México). |

## 🌐 Internacionalización

La página es bilingüe (Español / Inglés) con un switcher de idioma integrado en la barra de navegación. El sistema i18n está implementado con un diccionario JavaScript inline que traduce todos los textos mediante atributos `data-i18n`.

## 🛠️ Stack Técnico

- **HTML5** — Estructura semántica con datos estructurados (Schema.org JSON-LD)
- **CSS3** — Diseño responsivo con variables CSS, glassmorphism, gradientes y micro-animaciones
- **JavaScript** — Cambio de idioma y scroll suave dentro del contenedor principal
- **Google Fonts** — Tipografías Outfit e Inter
- **Font Awesome 6** — Iconografía

## 📱 Responsive

Diseño adaptable con breakpoints en `1200px`, `1024px` y `768px` para una experiencia óptima en desktop, tablet y móvil.

## 🔍 SEO

- Meta tags primarios (title, description, keywords)
- Open Graph para Facebook, LinkedIn y WhatsApp
- Twitter Cards
- Schema.org JSON-LD (`ProfessionalService`)
- Etiquetas `hreflang` para contenido multilingüe
- URL canónica
